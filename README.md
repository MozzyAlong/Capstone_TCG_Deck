# Welcome to TCG Deck Builder
Powered by **TCGDex API** and **Google Gemini**.

## Features
* Card Searching from API
* Manual creation of Card Decks
* Automatic creation of Card Decks with Google Gemini
* Decks can be made public for sharing
* Public Decks can have likes and comments

## Tech Stack
* NextJS hosting with Tailwind
* MongoDB Database
* TCGDex API
* Google Gemini API

## Installation and Running
```bash
git clone https://github.com/MozzyAlong/Capstone_TCG_Deck.git

cd Capstone_TCG_Deck

npm install

npm run dev
```
